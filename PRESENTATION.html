Rental outbound voice agent

POC: calling cleaning services for urgent scheduling needs
1 / 12

The problem

"As a short-term rental host facing a same-day cleaning cancellation, I want to delegate the calling-around work to an AI voice agent, so I can recover the turnover before guest check-in without dropping what I'm doing to coordinate backup cleaners myself."

Scenario: short-term rental host has a last-minute cleaning cancellation and needs a replacement before next check-in — ASAP.

Why a voice agent: urgent and stressful, hosts are often hands-off, zero onboarding cost, immediate outcome after the call.

Core decisions

ComponentChoiceReason
LLM, TTS, STT OpenAI Realtime gpt-realtime One low-latency streaming stack for speech-in, reasoning, speech-out.
Telephony Twilio Programmable Voice Easy setup, fast path to outbound calls.
Orchestration LiveKit SIP & Agents Avoids custom audio bridging; provides VAD, turn detection, Realtime integration, tool calling.
State Dataclasses + JSON snapshots Easy to inspect for POC.
Architecture boundary LLM extracts, Python decides Viability classification is deterministic; keeps agent behavior testable and the gold-set meaningful.
Evaluation Eval runner + LLM judge Deterministic gold-set for regressions; LLM-as-judge for interaction quality.

Learnings & future work

Learnings

  • OpenAI Realtime: rate limits and connection timeouts surface fast under load
  • VAD + barge-in: interruptions cut off mid-token; turn detection still needs tuning
  • Eval limitation: gold-set is transcript replay — doesn't exercise STT or audio dynamics

Future work

  • Modular TTS/STT for additional models & scale
  • Gold-set with agent personas & real back-and-forth, not transcript replay
  • Observability: dashboards for routing quality, latency, cost
  • Parallelize calls to multiple cleaners
  • State storage in a real DB; outcome notifications
